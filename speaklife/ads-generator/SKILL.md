## Phase 2 — Generate `prompts.json`

### Trigger phrases
- "Generate ads for [pillar]"
- "Build prompts for [template range]"
- "Run template 1–5"
- "Make an ad for anxiety/identity/grace/love/health"
- "Generate prompts.json"
- "Prep the ad pipeline for [season]"

### What you do in Phase 2

1. **Read brand-dna.md** — extract the IMAGE GENERATION PROMPT MODIFIER (Section 6)
2. **Read template-prompts.md** — identify the requested templates
3. **Read relevant sections of PILLARS.md / ad-angles.json** — get real hook text, declarations, scriptures
4. **Fill in all [BRACKETED PLACEHOLDERS]** — with brand-specific, emotionally specific content
5. **Prepend the prompt modifier** to every prompt
6. **Write `brands/speaklife/prompts.json`**

### Key rules — non-negotiable

| Rule | Detail |
|---|---|
| **Always prepend prompt modifier** | First ~86 words of every prompt = IMAGE GENERATION PROMPT MODIFIER from brand-dna.md |
| **Always tag aspect_ratio** | Required field for every prompt in prompts.json |
| **Always set needs_product_images** | Must match the template spec — never assume false |
| **Use real pain states** | Pull from PILLARS.md or ad-angles.json — never generic "anxiety" |
| **Gold = payoff word** | Every declaration ends on a gold (#C9A84C) keyword |
| **Montserrat Bold** | Specify this font explicitly in every prompt |
| **No cleavage, no bright backgrounds** | Hard brand rule — ensure prompts enforce this |
| **HYPER-SPECIFIC pain states** | "wake up anxious before feet hit the floor" > "feel anxious" |

### prompts.json structure

```json
{
  "brand": "speaklife",
  "generated_at": "ISO-8601 timestamp",
  "pillar": "anxiety",
  "prompts": [
    {
      "id": "T01",
      "name": "Declaration Hook Card",
      "aspect_ratio": "4:5",
      "needs_product_images": false,
      "prompt": "[FULL PROMPT — modifier prepended + placeholders filled]"
    },
    {
      "id": "T02",
      "name": "Quote Card with Scripture",
      "aspect_ratio": "1:1",
      "needs_product_images": false,
      "prompt": "..."
    }
  ]
}
```

**Field rules:**
- `id` — T01 through T20, zero-padded
- `name` — exact name from template-prompts.md
- `aspect_ratio` — "4:5", "1:1", or "9:16" — must match template spec
- `needs_product_images` — boolean, must match template spec
- `prompt` — must begin with the 86-word IMAGE GENERATION PROMPT MODIFIER verbatim

## Phase 3 — Run `generate_ads.py`

### Prerequisites checklist
- [ ] `FAL_KEY` environment variable is set
- [ ] `brands/speaklife/prompts.json` exists (created in Phase 2)
- [ ] `brands/speaklife/product-images/` contains app screenshots (for templates with `needs_product_images: true`)

### Commands

**Full run — all templates in prompts.json at 2K:**
```bash
cd /home/node/.openclaw/workspace/speaklife/ads-generator
export FAL_KEY=your_key_here
python references/generate_ads.py brands/speaklife
```

**Selective templates:**
```bash
python references/generate_ads.py brands/speaklife --templates 1,3,7
python references/generate_ads.py brands/speaklife --templates T01,T03,T07
```

**Different resolution:**
```bash
python references/generate_ads.py brands/speaklife --resolution 1K
python references/generate_ads.py brands/speaklife --resolution 4K
```

**Dry run (no API calls — just validates):**
```bash
python references/generate_ads.py brands/speaklife --dry-run
```

**Regenerate a single template (T07 only):**
```bash
python references/generate_ads.py brands/speaklife --templates T07
```

## Interaction Patterns

### "Generate ads for anxiety"
1. Read `PILLARS.md` — Anxiety & Fear section
2. Read `ad-angles.json` — anxiety pillar (3AM-thoughts, fear, overwhelmed, panic, worry)
3. Select best pain states per template
4. Fill all 20 templates → write `brands/speaklife/prompts.json`
5. Report: "prompts.json written. Run `python references/generate_ads.py brands/speaklife` to generate."

### "Run template 1-5"
1. Generate Phase 2 output for T01–T05 only (or if prompts.json exists, filter it)
2. Report the 5 filled prompts
3. Run: `python references/generate_ads.py brands/speaklife --templates 1,2,3,4,5`

### "Regenerate T07"
1. Re-fill T07 with fresh placeholder content (different pain state if previous didn't resonate)
2. Update or create `brands/speaklife/prompts.json` with just T07
3. Run: `python references/generate_ads.py brands/speaklife --templates T07`

### "Generate ads for Lent / this season"
1. Read `LEARNINGS.md` — Seasonal Category Amplifiers section
2. Fill T20 (Seasonal/Lent Hook) with current season details
3. Also consider T09 (Scripture Anchor) with resurrection scripture
4. Generate and report

### "Test a new hook"
1. User provides hook text
2. Map it to the most appropriate template (usually T01 or T04)
3. Fill the template with that hook
4. Generate that single template
