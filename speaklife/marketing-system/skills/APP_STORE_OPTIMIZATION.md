## ASO Audit Checklist

Run this checklist whenever rankings drop or quarterly:

### Title (30 chars max)
- [ ] Primary keyword included
- [ ] Brand name prominent
- [ ] Compelling, not generic
- Current: "SpeakLife - Daily Declarations"

### Subtitle (30 chars max)
- [ ] Secondary keyword included
- [ ] Benefit-driven
- [ ] Different from title keywords

### Keywords Field (100 chars)
- [ ] No spaces after commas (wastes chars)
- [ ] No repeat of title/subtitle words (App Store ignores duplicates)
- [ ] Mix of high-volume and long-tail
- [ ] Competitor brand names (where allowed)

### Description
- [ ] First 3 lines are the hook (visible before "more")
- [ ] Social proof in first paragraph (ratings, user count)
- [ ] Feature bullets scannable
- [ ] CTA at the end

### Screenshots (up to 10)
- [ ] First screenshot is the strongest hook
- [ ] Text overlays readable at thumbnail size
- [ ] Shows real app value, not just UI
- [ ] Consistent brand aesthetic
- [ ] A/B test candidates identified

### Ratings & Reviews
- [ ] Overall rating above 4.7?
- [ ] Recent reviews (last 30 days) positive?
- [ ] Responding to negative reviews?
- [ ] In-app review prompt timing optimized?
