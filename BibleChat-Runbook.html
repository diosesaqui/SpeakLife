Bible Chat — Maintenance Runbook

Everything you need to update, deploy, debug, and price the Bible Chat feature. Bookmark this file.

Project: speaklife-3e5c4  •  Model: claude-haiku-4-5-20251001  •  Function region: us-central1

◆Overview

Bible Chat replaces the old Warrior Room tab. Users ask about real-life struggles and get warm, scripture-rooted answers from Claude. It's a premium feature: non-subscribers get 3 free messages, then a benefits paywall.

The golden rule of updates: there are only two things you'll ever change —
  1. The AI's behavior (tone, rules, scripture style) → edit the system prompt in the Cloud Function, then redeploy. no App Store release
  2. The UI / chat screen (how it looks) → edit the Swift files, then ship an App Store build. needs release

◆How it works

iPhone appBibleChatConversationView
→
Cloud FunctionbibleChat (holds the key)
→
AnthropicClaude Haiku 4.5

The app never talks to Anthropic directly. It calls our Cloud Function, which holds the API key, checks premium, enforces the free limit, sends a cached system prompt, and logs token usage. This keeps the key off the phone and lets us change the AI's behavior without an app update.

  • Rolling memory: only the last 8 messages (~4 exchanges) are sent each turn — keeps it conversational and cheap.
  • Cached system prompt: the instructions are cached server-side (~90% cheaper on repeat reads).
  • Output cap: max_tokens: 600 + "keep replies under ~220 words" in the prompt.

⚠The API key — read this

There are TWO separate Anthropic keys. Don't confuse them. The onboarding/declaration generator and the Bible Chat function read from different places.
Onboarding / DeclarationsBible Chat
Key lives inFirebase Remote Config
anthropic_api_key		Firebase Secret Manager
ANTHROPIC_API_KEY
Read byThe app, on the deviceThe Cloud Function, server-side
Set viaFirebase Console → Remote Configfirebase functions:secrets:set

If onboarding works but Bible Chat returns a 401 "invalid x-api-key," the Secret Manager value is wrong. Fix it by copying the working value from Remote Config into the secret:

cd functions
firebase functions:secrets:set ANTHROPIC_API_KEY    # paste key at the masked prompt
firebase deploy --only functions:bibleChat       # required: rebinds the new value
If you ever rotate the key in the Anthropic console, update BOTH places — Remote Config and the secret — or one of the two features will break.
Setting a secret tip — the label is ANTHROPIC_API_KEY; the key (sk-ant-…) goes in the masked "Enter a value" prompt that appears after. Never paste the key as the name.

◆Edit the AI's behavior (tone, rules, scripture)

Everything about how the AI talks lives in one place: the SYSTEM_PROMPT constant near the top of functions/bibleChat.js. It controls:

  • Personality & warmth
  • The topic fence (declines sports/trivia/off-topic, redirects to faith)
  • Scripture style (currently NIV preferred, always cites verses)
  • Reply length and safety rules (no medical/legal/financial advice; crisis handling)

Edit the text, then redeploy — no app update needed:

cd functions
firebase deploy --only functions:bibleChat
Examples you might want later: lock to a specific translation (ESV/KJV), make the off-topic redirect softer, allow longer answers (also raise max_tokens), or add denominational nuance. All one edit to SYSTEM_PROMPT + redeploy.

◆Cost & monitoring

Pricing (Claude Haiku 4.5)

InputOutputCached read
$1.00 / 1M tokens$5.00 / 1M tokens$0.10 / 1M tokens

Real-world cost is about $0.003–0.005 per message. Even a heavy user (~150 msgs/mo) costs under $1 — well below subscription revenue. No usage cap is needed; the topic fence + length cap keep it bounded.

Where the real numbers are: every message logs tokens to Firestore at bibleChatUsage/{appUserId} — fields totalMessages, inputTokens, outputTokens, cacheReadTokens, freeMessagesUsed. Sum these to see actual spend per user. The Anthropic Console also shows total spend.

◆Paywall value props

Two things sell Bible Chat:

  • The benefits splash shown after free messages run out → BibleChatPaywallSplash in Views/Bible/BibleChatView.swift (edit the benefits array).
  • The main subscription paywall → HighConversionPaywallView.swift. The succinct outcome-style props are in succinctValueProps (toggle on with the useSuccinctPaywallValueProps flag).

Both are Swift — changes need an App Store build (the flag toggle is instant, but the copy itself ships in the binary).

◆Local testing

Easiest: just run from Xcode. Debug builds show the Bible Chat tab and call the live deployed function — no setup.

To test the function fully offline against a local emulator:

# put your key in functions/.secret.local (gitignored):
ANTHROPIC_API_KEY=sk-ant-...

cd functions
firebase emulators:start --only functions,firestore

# in Xcode: Edit Scheme → Run → Environment Variables:
USE_FIREBASE_EMULATOR = 1

◆Troubleshooting

First step always: test the function directly (no app needed)

curl -sS -i -X POST https://us-central1-speaklife-3e5c4.cloudfunctions.net/bibleChat \
  -H "Content-Type: application/json" \
  -d '{"appUserId":"diag","isPremiumClaim":true,"messages":[{"role":"user","content":"hello"}]}'

Then read the logs

firebase functions:log --only bibleChat -n 20
SymptomMeaning & fix
App shows "Something went wrong"The function returned an error. Run the curl test to see which.
502 ai_unavailable + log 401 invalid x-api-keyWrong Anthropic key in Secret Manager. See The API key. Re-set it and redeploy.
Log: RC lookup 403The RevenueCat secret is wrong/missing. Harmless — the function falls back to the app's premium flag. To remove the wasted call, set the real RC sk_ secret or ask to strip RC out.
Premium users hit the paywallRevenueCat can't confirm them. Same as above — fallback uses the app flag, so confirm the app is sending the right premium status.
Tab missing in productionenableAIFeatures is false in Remote Config. Set it true.
Off-topic answers / wrong toneEdit SYSTEM_PROMPT in bibleChat.js + redeploy.
